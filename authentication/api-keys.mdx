---
title: Secret keys
description: Server-side keys with full access to your organization's API.
---

A secret key gives full API access to your organization. Keep it on your servers only.

```
sk_live_<your_key>
```

## Usage

Send it as a Bearer token:

```bash
POST /api/public/tenants
Authorization: Bearer sk_live_...
Content-Type: application/json

{
  "externalTenantId": "workspace_abc123",
  "name": "Acme Corp",
  "externalUserId": "user_123",
  "ownerEmail": "admin@acme.com"
}
```

The Node and PHP SDKs take it once, when you create the client:

```typescript
const crovver = new CrovverClient({ apiKey: process.env.CROVVER_SECRET_KEY! });
```

## What it can do

Everything the public API offers, including:

- create customers
- create checkout sessions
- consume credits
- allocate seats and create proration checkouts
- cancel and renew subscriptions
- list plans, subscriptions and invoices

## Keep it secret

<Warning>
  Never put a secret key in browser code, in an environment variable prefixed `NEXT_PUBLIC_`, or in any file that is bundled for the browser.
</Warning>

```bash
# server-only environment
CROVVER_SECRET_KEY=sk_live_...
```

## Creating and rotating keys

In the dashboard, go to **Developers → API Keys**. A key is shown once, when it is created, so store it right away. If you lose one, create a new key and revoke the old one.
