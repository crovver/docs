---
title: List Supported Providers
api: GET /api/public/supported-providers
description: The payment providers Crovver supports, with their currencies and capabilities.
---

Lists every payment provider Crovver supports, whether or not your organization has connected it. Use it if you build your own pricing page and want to offer only the providers that handle a currency. No key is needed.

<RequestExample>
```bash cURL
curl "https://app.crovver.com/api/public/supported-providers"
```

```typescript Node.js
const { providers } = await crovver.getSupportedProviders();
```
</RequestExample>

Each provider also carries setup notes for the dashboard. Only `code`, `name` and `capabilities` matter to your app.
