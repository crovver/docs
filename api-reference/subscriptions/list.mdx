---
title: List Subscriptions
api: GET /api/public/subscriptions
description: A customer's live subscriptions, with each plan's features and credit allowances.
---

Returns the customer's subscriptions that are `trial`, `active` or `past_due`, plus canceled ones still inside their paid period (`pending_cancel`). A customer holds at most one per product.

## Query Parameters

<ParamField query="requestingEntityId" type="string" required>
  Your ID for the customer: the `externalTenantId`, or the user ID for a D2C customer.
</ParamField>

## Authentication

Requires a **secret key** (`Authorization: Bearer sk_live_...`).

<RequestExample>
```bash cURL
curl "https://app.crovver.com/api/public/subscriptions?requestingEntityId=workspace_123" \
  -H "Authorization: Bearer sk_live_..."
```

```typescript Node.js
const { subscriptions } = await crovver.getSubscriptions("workspace_123");
```

```php PHP
$result = $client->getSubscriptions('workspace_123');
```
</RequestExample>
