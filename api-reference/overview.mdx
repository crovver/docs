## Base URL

```
https://app.crovver.com
```

Every endpoint in this reference lives under `/api/public/`.

## Authentication

Every endpoint needs a key. See [Authentication](/authentication/overview) for details.

```bash
# Public key: browser, React SDK. Only the endpoints listed on the Public keys page.
x-public-key: pk_live_...

# Secret key: your backend. Every endpoint.
Authorization: Bearer sk_live_...
```

A public key sent to a secret-key endpoint is refused with `401`, including in the `Authorization` header.

## Response Format

All responses follow this envelope:

```json
{
  "success": true,
  "data": { ... },
  "error": null,
  "meta": { ... }
}
```

### Error Response

```json
{
  "success": false,
  "data": null,
  "error": {
    "message": "Human-readable error message",
    "code": "ERROR_CODE"
  }
}
```

## Common Error Codes

| Code | HTTP | Description |
|---|---|---|
| `MISSING_PUBLIC_KEY` | 400 | `publicKey` query param not provided |
| `INVALID_PUBLIC_KEY` | 401 | Public key not found or inactive |
| `TENANT_NOT_FOUND` | 404 | No tenant with the given external ID |
| `NO_SUBSCRIPTION` | 402 | The customer has no live subscription, on credit endpoints |
| `SUBSCRIPTION_ENDING` | 409 | Checkout for a product whose canceled subscription is still in its paid period |
| `CURRENCY_NOT_SUPPORTED` | 422 | The plan or add-on has no price in that currency |
| `MISSING_REQUIRED_FIELDS` | 400 | Required body/query params missing |
