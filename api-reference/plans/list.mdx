---
title: List Plans
api: GET /api/public/plans
description: Get every plan your organization currently sells.
---

Returns every published plan of every published product in your organization. Use it to build your own pricing page. Drafts, archived plans and hidden plans are not listed.

## Authentication

Requires a **secret key** (`Authorization: Bearer sk_live_...`). Call it from your backend. The hosted pricing page needs no call from you.

## Query Parameters

<ParamField query="productSlug" type="string">
  Only list the plans of this product.
</ParamField>

<RequestExample>
```bash cURL
curl "https://app.crovver.com/api/public/plans" \
  -H "Authorization: Bearer sk_live_..."
```
</RequestExample>

Prices are numbers in the currency's normal unit: `29` means 29.00. A free plan has `isFree: true`, no `prices`, and `pricing.amount: null`. Extra billing periods and country prices set in the dashboard are not listed here.

`seatTiers` lists the seat bands of a [tiered plan](/concepts/plans#plan-types), for every currency, ordered by currency then `minQuantity`:

```json
"seatTiers": [
  { "currency": "USD", "minQuantity": 1,  "maxQuantity": 10,   "price": "80.00" },
  { "currency": "USD", "minQuantity": 11, "maxQuantity": 50,   "price": "250.00" },
  { "currency": "USD", "minQuantity": 51, "maxQuantity": null, "price": "400.00" }
]
```

Each band's `price` (a two-decimal string) is the whole period's price for any seat count from `minQuantity` to `maxQuantity`; `null` marks the open top band. A tiered plan has `basePrice` and `perSeatPrice` of 0, and checkout refuses a seat count no band holds with `422 NO_BAND_FOR_QUANTITY`. `seatTiers` is `[]` for every other plan.

<Note>
  `plans[].product.type` (`b2b` or `d2c`) is the customer type of the plan's product, and decides whether checkout keys
  the tenant on `externalTenantId` or `externalUserId`. `organization.type` is **deprecated**: one organization may sell
  both kinds of product, so it carries the products' shared type, and `b2b` when they differ. The 2.0.0 SDKs no longer expose it.
</Note>
