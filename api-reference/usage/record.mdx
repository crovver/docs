---
title: Record Usage (Deprecated)
api: POST /api/public/record-usage
description: Deprecated. Use POST /api/public/credits/consume instead.
---

<Warning>
  This endpoint is deprecated and **usage sent to it is never counted**: it writes to a log that nothing reads, so it neither reduces a customer's allowance nor blocks them. Use [`POST /api/public/credits/consume`](/api-reference/credits/consume) instead. It deducts from the customer's credits, is idempotent through `idempotencyKey`, and returns the remaining balance in one call.
</Warning>

Records a usage event for a tenant. Kept only so older integrations don't fail.

## Request Body

<ParamField body="requestingEntityId" type="string" required>
  The external tenant ID
</ParamField>

<ParamField body="metric" type="string" required>
  The metric to record (must match a key in `plan.limits`)
</ParamField>

<ParamField body="value" type="number">
  Amount to add. Defaults to `1`.
</ParamField>

<ParamField body="metadata" type="object">
  Optional context (e.g., which user triggered the event)
</ParamField>

## Authentication

Requires a **secret key** (`Authorization: Bearer sk_live_...`).

<RequestExample>
```bash cURL
curl -X POST "https://app.crovver.com/api/public/record-usage" \
  -H "Authorization: Bearer sk_live_..." \
  -H "Content-Type: application/json" \
  -d '{
    "requestingEntityId": "workspace_123",
    "metric": "api_calls",
    "value": 1,
    "metadata": { "endpoint": "/api/export", "userId": "user_456" }
  }'
```
</RequestExample>

<ResponseExample>
```json 201
{
  "success": true,
  "data": {
    "message": "Usage recorded",
    "metric": "api_calls",
    "recordedValue": 1
  }
}
```
</ResponseExample>
