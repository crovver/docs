## Installation

```bash
npm install crovver-node
# or
pnpm add crovver-node
# or
yarn add crovver-node
```

**Requirements:** Node.js 18+. TypeScript is optional but fully supported.

## Initialize the Client

```typescript
import { CrovverClient } from "crovver-node";

const crovver = new CrovverClient({
  apiKey: process.env.CROVVER_SECRET_KEY!,
});
```

### Configuration Options

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `apiKey` | string | required | Your secret API key (`sk_live_...`) |
| `baseUrl` | string | `https://app.crovver.com` | Override the API URL |
| `timeout` | number | `30000` | Request timeout in milliseconds |
| `maxRetries` | number | `3` | Retry attempts for server errors |
| `debug` | boolean | `false` | Log requests and responses |
| `logger` | function | `undefined` | Custom logger: `(message, data?) => void` |

## Tenant Management

```typescript
// Create a tenant (B2B: workspace or user)
const tenant = await crovver.createTenant({
  externalTenantId: "workspace_abc123",
  name: "Acme Corp",
  externalUserId: "user_123",
  ownerEmail: "admin@acme.com",
});

// Retrieve a tenant
const tenant = await crovver.getTenant("workspace_abc123");
```

The ID you pass as `externalTenantId` is your own ID for the customer. The dashboard lists the tenant under **Customers**. Pass `ownerEmail`: it becomes the customer's billing email, which the customer needs to sign in to their billing page. An email set in the dashboard is never overwritten.

## Credits

Credits meter usage against a plan's allowances. Each pool is keyed by a meter key, such as `ai_tokens`.

### Check balance

```typescript
const balance = await crovver.credits.balance({ tenantId: "workspace_abc123" });

for (const pool of Object.values(balance)) {
  console.log(`${pool.poolKey}: ${pool.total} of ${pool.limit} left`);
}
```

The result is keyed by pool. Each pool has `baseRemaining` (plan credits), `addonRemaining`, `total`, `limit`, `limitBehavior` and `nextExpiry`.

### Consume credits

`consume` is idempotent. Sending the same `idempotencyKey` twice returns the first result and deducts nothing.

```typescript
const result = await crovver.credits.consume({
  tenantId: "workspace_abc123",
  poolKey: "ai_tokens",
  amount: 50,
  idempotencyKey: `generate-${job.id}`,     // stable per action
  metadata: { feature: "summarise" },        // optional
});

if (result.result === "blocked") {
  // The allowance ran out. Nothing was deducted; result.remaining says what is left.
  // Offer an add-on or an upgrade.
} else if (result.result === "warning") {
  // Deducted, but this tracked pool is now over its allowance.
}
```

**`ConsumeInput` fields:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `tenantId` | string | Yes | Your ID for the customer |
| `poolKey` | string | Yes | The meter key, such as `ai_tokens` |
| `amount` | number | Yes | Positive whole number of units to deduct |
| `idempotencyKey` | string | Yes | Unique per action; prevents double deduction |
| `subscriptionId` | string | No | Target one subscription, for customers with more than one |
| `metadata` | object | No | Stored with the consumption event |

**`ConsumeResponse` fields:**

| Field | Type | Description |
|-------|------|-------------|
| `result` | `"allowed" \| "warning" \| "blocked"` | Outcome of the deduction |
| `remaining` | number | Credits left in the pool |
| `alreadyProcessed` | boolean | `true` when the idempotency key was already seen |
| `poolKey` | string | Echoed pool key |

To scope a balance or consume call to one product by its slug, call the REST endpoints with `productSlug`. See [Consume credits](/api-reference/credits/consume).

## Add-ons

Add-ons let customers buy extra credits without changing plan.

### List available add-ons

```typescript
const addons = await crovver.addons.listAvailable("workspace_abc123");

for (const addon of addons) {
  console.log(`${addon.display_name}: ${addon.credit_qty} credits for ${addon.currency} ${addon.amount}`);
}
```

Only add-ons compatible with the customer's current plan are listed, priced in the subscription's currency.

### Purchase an add-on

```typescript
const purchase = await crovver.addons.purchase("workspace_abc123", {
  addonId: addon.id,
  currency: addon.currency,
  idempotencyKey: `addon-${order.id}`,
  successUrl: "https://yourapp.com/billing/success",
  cancelUrl: "https://yourapp.com/billing/cancel",
});

if (purchase.requiresPayment) {
  // Send the customer to pay
  redirect(purchase.checkoutUrl!);
} else {
  // A free add-on: the credits are already granted
  console.log(`${purchase.creditQty} credits added`);
}
```

### Get active add-on credits

```typescript
const active = await crovver.addons.getActive("workspace_abc123");

for (const pool of active) {
  console.log(`${pool.pool_key}: ${pool.addon_remaining} add-on credits left`);
}
```

## Seats

For per-seat plans, record which of your users hold a seat, and charge for more seats when a team grows.

```typescript
// Give users seats on the customer's subscription
await crovver.capacity.bulkAllocate({
  requestingEntityId: "workspace_abc123",
  users: [
    { externalUserId: "user_123", email: "jane@acme.com" },
    { externalUserId: "user_456", email: "sam@acme.com" },
  ],
});

// List who holds a seat
const allocations = await crovver.capacity.getAllocations({ requestingEntityId: "workspace_abc123" });

// Buy more seats, prorated for the rest of the period
const upgrade = await crovver.createProrationCheckout({
  externalTenantId: "workspace_abc123",
  newCapacity: 12,
  successUrl: "https://yourapp.com/team?seats=added",
  cancelUrl: "https://yourapp.com/team",
});

if (upgrade.requiresPayment) redirect(upgrade.checkoutUrl!);
```

See [Seat-based billing](/guides/seat-based-billing) for the full flow.

## Usage Tracking (deprecated)

<Warning>
  `recordUsage` and `checkUsageLimit` are deprecated. `recordUsage` writes to a log that nothing reads, so usage recorded through it is never counted against an allowance. Use [`credits.consume`](#credits) and [`credits.balance`](#check-balance) instead.
</Warning>

```typescript
// ❌ Deprecated — use credits.consume() instead
await crovver.recordUsage("workspace_abc123", "api_calls", 1);

// ❌ Deprecated — use credits.balance() instead
const limit = await crovver.checkUsageLimit("workspace_abc123", "api_calls");
console.log(`${limit.current} / ${limit.limit}`);
```

## Error Handling

```typescript
import { CrovverClient, CrovverError } from "crovver-node";

try {
  const canAccess = await crovver.canAccess("workspace_abc123", "advanced-analytics");
} catch (error) {
  if (error instanceof CrovverError) {
    error.message;      // Human-readable message
    error.statusCode;   // HTTP status code
    error.code;         // API error code string
    error.isRetryable;  // Whether the SDK already retried
  }
}
```

<Note>
  5xx errors, 429, and 408 responses are retried automatically with exponential backoff. Checkout endpoints are **never** retried to prevent duplicate charges.
</Note>
